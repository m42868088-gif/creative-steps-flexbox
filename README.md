# Creative Steps

Адаптивная одностраничная верстка по мотивам макета **Grid Repeater with Numbers** (вариант 2Р2).

## Что использовано

- семантический HTML5;
- Flexbox для основной композиции и сетки карточек;
- относительные единицы `vh`, `vw`, `%`, `clamp()`;
- медиазапросы для планшетов и смартфонов;
- доступные focus-состояния и поддержка `prefers-reduced-motion`;
- чистые HTML, CSS и JavaScript без зависимостей.

## Локальный запуск

Откройте `index.html` в браузере или запустите статический сервер:

```bash
python3 -m http.server 4173
```

После этого сайт будет доступен по адресу `http://localhost:4173`.
